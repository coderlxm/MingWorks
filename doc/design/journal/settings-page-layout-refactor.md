# Journal 站点设置页（/me/settings）排版重构方案

## 现状问题

- 桌面端依赖 `ElTabs` 左侧页签，移动端切成横向滚动页签；五个分区在 375px 宽度下无法完整显示，两端交互模型不同。
- 各分区自带标题，字号、容器背景（`surface-page` / `surface-card`）、卡片内边距各不相同，公开资料是双栏编辑 + 预览，联系方式是双列卡片，频道标签是三列卡片，简历与投稿又是整块面板，视觉语言不统一。
- 保存方式混杂：前三个分区共用底部保存条（靠 `margin-left: 12.9rem` 对齐页签），简历有独立“保存权限”，投稿链接即时生效，用户难以判断哪些修改需要保存。
- 校验错误通过 toast 反复弹出，退出登录和返回入口挤在同一行。

## 布局结构

```text
桌面（≥ 800px）
┌────────────────────────────────────────────────────┐
│ ← 返回我的资产                                      │
│ SITE SETTINGS / 站点设置 / 说明                      │
├──────────────┬─────────────────────────────────────┤
│ 站点资料       │ 分区标题 + 说明                        │
│  公开资料 ●    │ ┌ 卡片：标题 / 说明 / 附加信息 ┐      │
│  联系方式      │ │ 内容                          │      │
│  频道标签      │ └ 卡片页脚（按需）              ┘      │
│ 内容与分享     │ ┌ 卡片 ┐                              │
│  个人简历      │ └──────┘                              │
│  投稿链接      │ [未保存：公开资料 · 放弃 · 保存]（仅有改动时） │
│ 账户          │                                       │
│  退出登录      │                                       │
└──────────────┴─────────────────────────────────────┘

移动（< 800px）
/me/settings            → 分组列表（与桌面侧栏同一组件、同一分组）
/me/settings?section=x  → 顶部“← 站点设置”，下方为与桌面完全相同的分区内容
```

- 桌面与移动共用同一份分区元数据（名称、说明、图标、分组）与同一个导航组件，仅呈现形态不同：桌面为粘性侧栏，移动为 iOS 式分组列表。
- 分区仍由 `?section=` 决定；桌面缺省显示“公开资料”，移动缺省显示索引列表。桌面切换分区使用 `replace`，移动从列表进入详情使用 `push`，系统返回手势可直接回到列表。
- 所有分区统一为 `SettingsSection`（标题、说明、分隔线）+ `SettingsCard`（标题、说明、右侧附加信息、内容、页脚），卡片统一 `surface-card` 背景与 `radius-card` 圆角，卡片内输入框统一 `border-strong` 描边。
- 字段一律“标签 + 说明 + 控件”纵向排列，桌面与移动只改变列数，不改变结构。

## 保存模型

- 公开资料、联系方式、频道标签属于同一次站点资料提交，归入“站点资料”分组；侧栏与列表以圆点标记有改动的分区。
- 统一保存栏仅在存在未保存修改时出现，粘附在内容区底部，展示“未保存：分区名”或当前校验错误，提供“放弃修改”和“保存修改”。
- 个人简历、投稿链接属于“内容与分享”分组，操作即时生效，各自的确认按钮放在所属卡片页脚，不进入统一保存栏。
- 校验错误不再反复 toast，改为在保存栏与字段计数中就地显示。

## 各分区内容

- 公开资料：“头像”卡片合并头像选择与名片预览；“介绍”卡片放 Bio 与自我介绍，计数与标签同行。
- 联系方式：单张卡片内的分隔行列表，开关位于行尾，启用后展开展示内容与跳转链接字段。
- 频道标签：每个频道一张卡片，右上角显示数量，标签以可排序胶囊呈现，底部为添加输入。
- 个人简历：“简历文件”卡片（文件信息与替换、下线）+“访问权限”卡片（选项网格、细节、页脚保存）。
- 投稿链接：“当前链接”卡片（状态、链接、二维码、撤销）+“创建链接”卡片（有效期选择与创建）。
