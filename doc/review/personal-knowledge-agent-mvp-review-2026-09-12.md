## 已修复的问题

| 级别 | 触发与影响 | 修复 |
| --- | --- | --- |
| P1 | 点击“打开原记录”：子组件传出数字 ID，页面按对象读取 `entryId`，形成 `entry=undefined`，来源跳转失效 | `AiView.vue` 统一接收数字 ID，沿用现有管理详情路径 |
| P1 | 回答生成期间切换会话再返回：重新读取的消息与迟到回答再次拼接，可重复显示问答；共享输入与请求状态也会跨会话干扰，首次建会话时可重复发送 | `aiChat.ts` 按会话保存消息、输入、加载与发送状态，原位替换本轮消息；创建期间限制重复操作。服务端同一会话禁止并行生成，上下文只取成对完成的问答。退出登录清空缓存并使旧请求失效，保存完成不再把已离开的页面强行切回编辑器 |
| P1 | 模型因长度上限等原因中断：原实现只判断内容非空，将残缺回答标记完成并允许保存 | `knowledgeAgentService.ts` 按结束原因判断完整性，中断直接暴露错误；工具超限也直接结束，不跳过后继续生成成功结果 |
| P1 | 对话区与输入区为横向 flex 排列，窄屏下输入区挤占对话并可能使发送操作超出可视区域；长内容缺少固定页面高度约束 | `AiView.vue` 改为上下排列，限定页面高度并允许输入框收缩，保留对话区内部滚动。该问题与修复依据为 CSS 布局规则 |

模型结束原因依据：[DeepSeek Chat Completions API](https://api-docs.deepseek.com/api/create-chat-completion/)。
